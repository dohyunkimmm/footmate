Closed Beta 데이터 이용 안내

FootMate 시범 서비스에서 실제 계정과 경기 참여 정보를 어떻게 사용하는지 알기 쉽게 정리한 안내입니다.

범위 안내: 이는 Beta 기능·데이터 이용에 대한 공개 설명이며, 사업자 식별정보와 법정 필수 항목의 최종 법률 검토가 완료된 개인정보 처리방침을 대신한다고 주장하지 않습니다. 정식 개인정보 처리방침의 운영 주체·연락처·보유기간 등은 공개 서비스 운영 전 별도 검토·고지가 필요합니다.

1. 실제 계정과 정보

이메일과 비밀번호 인증은 Supabase Auth를 사용합니다. 이름은 선택 입력입니다. 프로필에 입력한 지역·포지션·레벨, 가입·로그인·경기 참가/취소·체크인·피드백 기록이 서버와 연결될 수 있습니다. Google·Kakao 로그인을 선택하면 해당 제공자의 인증 화면으로 이동합니다.

2. 이용 목적

계정 인증, 경기 조회·자리 확인·참가 상태 및 정원 관리, 운영상 공지·알림·오류 복구에 활용합니다. 경기 추천의 AI는 요청 조건을 해석하고 실제 경기 후보·정원은 서버 데이터를 기준으로 합니다.

3. 외부 서비스·알림

서버·인증·저장소는 Supabase를 사용하고, 설정된 경우 경기 관련 이메일은 Resend를 통해 발송할 수 있습니다. 브라우저 Web Push는 사용자가 직접 권한을 허용한 경우에만 요청합니다. 결제(PG)는 연동하지 않았으며 베타는 무료 참가입니다.

4. 조회·삭제

로그인 후 MY/계정 영역에서 자신의 참가 정보와 프로필을 확인할 수 있습니다. 계정 및 관련 기록 삭제 기능은 별도 확인 절차를 거쳐 제공됩니다. 이미 발송한 외부 이메일이나 감사·보안 목적으로 법령상 별도 보존할 정보의 취급은 정식 방침 확정 시 추가 안내가 필요합니다.

5. Demo와의 구분

Interactive Demo는 브라우저에서만 저장되는 샘플 기록이며 Closed Beta 계정과 자동 동기화되지 않습니다. Demo의 참가비와 환불 기준은 예시이고 실제 청구·환불이 일어나지 않습니다.
