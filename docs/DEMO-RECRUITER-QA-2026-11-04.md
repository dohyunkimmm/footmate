## 채용 담당자 관점

**강점**
- 풋살에 한정된 문제 정의, Find → Decide → Join → Play → Return 흐름과 선택 조건 기반 추천.
- 실제 후보 내 AI 순서 변경·실패 시 규칙 기반 대체, 추천 이유·잔여 자리 근거 제공.
- 인증·참가·정원·알림·운영자 권한·동의 후 측정 등 구현/운영 경계와 고지.
- 사업성과 12개월 예상 ROI의 마이너스 시나리오까지 공개해 투자 중단/확장 조건을 명확히 제시.

**보완 과제**
- 핵심 데모 링크는 포트폴리오에서 1클릭 접근 가능해야 함. 기본 /demo에서 설정을 전부 거치지 않도록 90초 검토 경로 노출.
- 실제 사용자 성과·재참가 전환·AI 추천 효과에 대한 검증 지표는 별도 확보. 화면 테스트 통과로 성과가 증명됐다고 해석하지 않음.
- Case Study의 추정 재무 수치와 실제 계약·지표는 구분. 복잡한 시뮬레이션이 첫인상 전체를 차지하지 않도록 상세 분석은 하위로.
- 입문 사용자와 채용 담당자의 빠른 탐색은 다른 목적이므로 링크를 명시적으로 구분.
