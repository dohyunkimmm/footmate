# FootMate v5.1.1 — AI Match Assistant Resilience Patch

## 목표

v5.1에서 추가한 AI Match Assistant의 사용자 가치는 유지하면서 Production에서 확인된 provider fallback 의존, 무한 대기 가능성, reload mode 불일치와 제품 설명 오차를 patch 범위에서 제거합니다.

새 기능을 추가하지 않습니다. recommendation / participation / matchday / return ownership, Find → Decide → Join → Play → Return, 16-section Case Study IA, browser persistence와 HITL(join/payment)을 유지합니다.

## Context → Plan → Tools → Guardrail → Observe

- **Context** — region / position / level browser state와 자연어 검색 요청
- **Plan** — region / position / level / maxPrice / maxDistanceMin / afterTime으로 구조화
- **Tools** — Vercel AI Gateway, deterministic recommendation, sample match catalog
- **Guardrail** — server/browser timeout, provider fallback 1회, allowlist/range validation, same-origin + JSON request guard, rate window, Vercel Function maxDuration, HITL
- **Observe** — version, mode, actual model, fallbackUsed, saved query/result, exact Production smoke

## Provider boundary

v5.1 exact Production 로그에서 `openai/gpt-5.4-mini`가 `403 no_providers_available`를 반환하고 `inclusionai/ling-3.0-flash-vl-free` fallback이 성공한 사실을 patch 입력으로 사용합니다.

v5.1.1 candidate default:

- primary: `inclusionai/ling-3.0-flash-vl-free`
- one provider fallback: `inclusionai/ling-3.0-flash-fin-free`
- override: `FOOTMATE_AI_MODEL`, `FOOTMATE_AI_FALLBACK_MODEL`
- auth: `AI_GATEWAY_API_KEY` 또는 Vercel deployment OIDC

Production acceptance는 실제 inference 응답의 `model`이 primary와 정확히 일치하고 `fallbackUsed === false`일 때만 통과합니다.

## Timeout / recovery

- provider request timeout: 3,000ms per attempt
- browser AI request timeout: 7,000ms
- Vercel Function maxDuration: 10s
- primary temporary/provider failure → provider fallback 1회
- provider path 최종 실패 또는 browser timeout → deterministic rules fallback
- fallback 후 input/button 활성 상태 복원

## Request / cost guard

- POST Origin host가 현재 Host와 일치해야 함
- `Sec-Fetch-Site`가 있으면 same-origin/none만 허용
- `application/json`만 허용
- body 16KB 제한
- per-IP 10 requests / 5min instance window
- instance-wide 60 requests / 5min window
- 429에 `Retry-After` 반환
- Vercel Function `maxDuration: 10`

이 guard는 application-level defense-in-depth입니다. Vercel edge WAF의 distributed rate-limit 정책을 새로 구성했다고 주장하지 않습니다.

## Persistence / State Consistency

기존 storage key `footmate:v5.1:ai`를 compatibility key로 유지합니다. 저장된 v5.1 state도 v5.1.1 runtime이 정규화해 읽습니다.

reload 후:

- UI mode badge
- `window.__FOOTMATE_AI__.mode`
- 저장된 structured constraints

가 같은 실행 mode를 가리켜야 합니다.
