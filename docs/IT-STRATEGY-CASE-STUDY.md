## 4. 수요·공급 시나리오

### 경유 예약·거래 규모 추정

제휴 공급·시간대·충원율을 변수로 둔 상향식 거래 규모 계획.

경기 공급에 경유 비중 60%·취소율 8%·취소 후 참가 완료율 97%를 적용해 월 완료 예약과 거래액을 계산했다.

월 완료 예약 = 공급처 × 주간 슬롯 × 4.33주 × 정원 × 충원율 × 경유 비중 × (1 − 취소율) × 완료율

**월 공급·거래 시나리오 · 경유·취소 반영 가정**

| 변수 | 보수 | 기준 | 확장 |
| --- | --- | --- | --- |
| 제휴 공급처 | 2곳 | 5곳 | 8곳 |
| 공급처당 주간 슬롯 | 2회 | 4회 | 6회 |
| 슬롯 정원 | 18명 | 18명 | 18명 |
| 충원율 | 50% | 75% | 90% |
| FootMate 경유 비중 | 60% | 60% | 60% |
| 취소율 / 취소 후 완료율 | 8% / 97% | 8% / 97% | 8% / 97% |
| 월 완료 예약 · 최종 반올림 | 83건 | 626건 | 1,803건 |
| 건당 거래금액 | 12,000원 | 12,000원 | 12,000원 |
| 월 완료 거래액 | 996,000원 | 7,512,000원 | 21,636,000원 |
| 수수료 매출 · 10% | 99,600원 | 751,200원 | 2,163,600원 |

**기준 모델의 거래 전환 · 월**

-  전체 공급**1,558.8석**

단계별 표시는 설명용이다. 계산은 중간 반올림 없이 수행하고, 최종 완료 예약을 정수 반올림한 뒤 거래액을 계산한다.

공급처는 경기 공급 계약을 체결할 운영 주체다. 동일 경기의 중복 등록을 제외한다. 완료 예약 건수와 고유 이용자 수는 별도로 집계한다.

#### 시장 규모 해석과 가정 교체 방법

전국 유료 개인 참가 고객 수는 추가 조사가 필요하다. 거래 규모는 확보 가능한 경기 공급을 기준으로 계산했다. 제휴 의향·주간 공급·실제 정원·충원율·객단가가 수집되면 각 입력을 관측값으로 교체한다.

12,000원과 수수료 10%는 FootMate의 사업 검토 가정이며 실제 가격·계약 조건은 제휴 협의와 실증을 통해 확정한다. 예약은 계산식 결과를 정수 반올림한 뒤 거래액을 계산했다.

#### 직접 운영안과 계산 범위

직접 운영 가정: 참가비 12,000원, 정원 18명, 구장 100,000원 + 매니저 40,000원 + 기타 고정 운영비 10,000원/경기. 건당 결제비 360원·변동비 500원을 차감하면 경기 단위 손익분기는 14명이다. 경기 단위 손익은 18명 충원 시 +50,520원, 12명 충원 시 −16,320원이다. 월 고정비·창업자 노동비용은 별도다.

모든 비용·수수료는 신규 가정이다. 세금·보증금·개발 초기 투자·취소 손실·사고 보상은 최종 투자안에서 별도로 산정할 항목이다. 계약 견적과 실증 데이터로 교체한 후 최종 투자안을 확정한다.

#### 참가·정원 관리의 설계 이유

마지막 자리에 요청이 몰리거나 같은 참가 요청이 반복될 때, 참가 상태와 잔여 자리가 서로 어긋나지 않도록 설계했다. 화면에 보이는 자리 수만으로 참가를 확정하지 않고 서버에서 다시 확인한다.

참가 확정과 정원 변경을 한 번에 처리하고, 이미 확정된 요청에는 기존 결과를 반환한다. 취소도 참가 상태와 잔여 자리를 함께 바꿔 반복 요청으로 자리가 여러 번 복원되는 것을 막는다.

가상 데이터를 이용한 테스트에서 로그인·참가·새로고침 후 상태 유지·취소 후 정원 복원을 확인했다. 실제 서버에서 여러 요청이 동시에 들어오는 상황과 현장 운영은 추가 검증 대상이다.

## 8. 실행계획·성과관리

### 8주 실증·투자 심사

#### 8주 예산·집행 통제

집행 상한 제안 · 현금 461만원 / 노동 기회비용 포함 831만원

계약·실증 시작 전 승인할 예산안이다. 초기 구축 300만원은 기존 계획의 상한이며 이미 지출한 비용이 아니다. 월 200만원의 노동 기회비용을 시간당 25,000원으로 환산하면 8주 약 148시간이다. 환산 단가와 실증 변동비 50만원은 추가 가정이다.

#### 8주 자원 산정·승인 범위

**8주 실증 자원 · 집행 상한 제안**

| 항목 | 산정·범위 | 8주 금액 |
| --- | --- | --- |
| 초기 구축 | 기존 초기 투자 계획. 필요한 범위만 착수 전 승인 | 3,000,000원 |
| 고정 운영 | 월 600,000원 × 8주 ÷ 4.33주 · 만원 단위 올림 | 1,110,000원 |
| 실증 변동비 | 모집·현장 지원 등 추가 집행 한도 가정. 고정비와 중복 제외 | 500,000원 |
| 현금 집행 상한 | 초기 구축 + 고정 운영 + 실증 변동비. 수익 차감 전 | 4,610,000원 |
| 노동 기회비용 | 월 2,000,000원 × 8주 ÷ 4.33주 · 만원 단위 올림 | 3,700,000원 |
| 총 자원 상한 | 현금 집행 상한 + 노동 기회비용 | 8,310,000원 |

고정 운영·노동비는 1개월 4.33주로 환산하고 각각 만원 단위로 올렸다. 변동비 50만원은 실측 원가가 아닌 별도 집행 한도다. 초기 구축비의 기존 투입분은 재집행하지 않으며, 참가비·수수료 수익은 한도에서 미리 차감하지 않는다.

계약 전 해지·환불·현장 안전·추가 부담 범위를 확인한다. 위 금액은 승인한 항목의 집행 상한으로, 손해배상 등 모든 우발손실의 최대치를 뜻하지 않는다. 확정 지출과 취소 불가 약정을 함께 기록하고, 예상 총집행이 한도를 넘기 전에 신규 발주·광고를 보류한다.

## 9. 종합 판단·근거

### 검토 결론·후속 과제

시장·사업모델·IT 투자 검토를 바탕으로 다음 의사결정의 조건을 제시한다.

#### IT 검토 범위
