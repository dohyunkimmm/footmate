> **과거 서비스기획 화면 검수 기록** · 본문의 01~11 등 번호는 2026-10-25~26 당시 화면 구성 기준입니다. 현재 공개 `/`는 IT기획·전략기획 9개 섹션이며, 현행 구성·수치는 [IT기획·전략기획 Case Study](IT-STRATEGY-CASE-STUDY.md)와 `src/case-study/nine-sections.js`를 우선합니다. 캡처는 해당 시점의 화면 근거로 보존합니다.

## 기본 미리보기와 본문 균형 · 2026-10-26

- 기본 화면은 세부 글자를 모두 읽는 원본 보기와 분리합니다. 일반 미리보기는 최대 280px, 제어 영역 발췌는 최대 240px로 제한합니다. 전체 캡처는 기존 확대 창에서 원본 크기 이상으로 확인합니다.
- 01 대표 이미지 영역은 PC에서 이미지 고유 높이가 그리드 행을 늘리지 않도록 하고, 옆 본문 내용에 맞춰 높이를 정합니다. 기본 이미지에서는 추천 카드 중심 영역을 보여줍니다.
- 07의 2열 구조는 유지하되 각 미리보기 높이와 간격을 줄입니다. 갤러리는 280px 공간을 미리 확보해 늦게 로드되는 이미지가 페이지를 추가로 늘리지 않게 합니다. 이전의 원본 대비 80% 최소 표시 크기 검사는 기본 이미지를 지나치게 키우므로 제거하고, 높이 상한·본문과 이미지의 균형·섹션 전체 길이 검사로 교체합니다.
- PC 1440/1920의 01 본문과 이미지 영역 높이 차이는 2px 이내, 대표 영역은 560px 미만, 01 섹션은 1100px 미만, 07은 2800px 미만을 확인합니다. 05·06·08·09·10의 기본 미리보기에도 높이 상한을 적용합니다.
- 이미지 파일, 문구, UI 구성, 확대 창의 원본은 바꾸지 않습니다. 기본 표시는 비율을 유지한 영역 발췌이며 이미지 내용을 늘리거나 합성하지 않습니다.

- `current-demo-home.png`: 추천 조건, 예시 경기, 잔여 자리, 상세·참가 버튼.
