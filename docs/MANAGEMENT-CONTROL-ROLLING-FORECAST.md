# FootMate 경영관리 · Rolling Forecast·예산 통제

> 현행 2027년 연간 계획, 상반기 **합성 거래 자료**, 하반기 공급 전망을 활용한 경영관리 검토안. 실제 고객·제휴 계약·매출·인력 채용·투자 집행 실적이 아니다.

## 직무 역할·검토 범위

FootMate의 핵심은 **사업계획 → 예산 수립 → 월간 차이 분석 → Rolling Forecast → CAPEX·인력 계획 → 투자 판단**이다. AI 구현·개발 QA는 계획 실현 가능성을 뒷받침하는 보조 근거로 두고, 별도의 PRD·UAT 사례와 중복하지 않는다.

| 관리 영역 | 기존 자료 | 이번 보완 |
| --- | --- | --- |
| 손익 모델 | 5개년 시나리오·월간 손익·12개월 ROI | 월별 전망의 갱신 근거·재예측 규칙 |
| 월별 경영관리 | 2027년 계획, 1~6월 합성 거래, 7~12월 계획 | 최근 3개월 추세를 반영한 7~12월 Rolling Forecast |
| 예산·비용 | 현금 고정비 월 60만 원·8주 집행 상한 | OPEX·CAPEX 후보·기회비용·추가 집행 분리 |
| 인력·생산성 | 월 노동 기회비용 200만 원 | 시간당 2만 5천 원 가정의 월 80시간·0.5 FTE 환산 |
| 경영 보고 | 월간 계획 대비 실적, 5개년 투자 결정 | 수정 전망의 원인·대안·중단/승인 조건 |

## 2027년 6월 기준 Rolling Forecast · 예시

기존 [월간 경영관리 페이지](../src/case-study/forecast.html#rolling-management)의 2027년 1~6월 가상 실적과 7~12월 계획을 대조한다. 4~6월의 최신 3개월을 추세 구간으로 사용한다.

1. **완료율 보정:** `직전 3개월 가상 완료 합계 ÷ 직전 3개월 계획 완료 합계` = 약 **95.14%**.
2. **건당 수수료 수익:** `직전 3개월 가상 수수료 매출 ÷ 가상 완료 예약` = 약 **1,202원**.
3. **건당 비용:** `(가상 수수료 매출 − 가상 현금 손익 − 월 현금 고정비 60만 원 × 3개월) ÷ 완료 예약` = 약 **1,057원**.
4. **7~12월 수정 전망:** `월 계획 완료 예약 × 보정률`을 최종 정수 반올림하고 `완료 예약 × (건당 수수료 수익 − 건당 비용) − 월 현금 고정비 60만 원`으로 계산한다.
5. **연간 수정 전망:** 1~6월 합성 실적 + 7~12월 수정 전망. 기존 연간 계획과 차이를 표시한다.

위 방식은 취소·노쇼 등으로 발생한 가상 비용을 최근 3개월 평균에 내재화한 단순화 예시다. 규모가 커질수록 단가·고정비가 일정하다고 단정할 수 없다. 소수점 내부 계산은 유지하고 표시는 반올림한다.

| 비교 항목 | 2027년 연간 기존 계획 | 6월 마감 후 재예측 시나리오 | 차이 |
| --- | ---: | ---: | ---: |
| 수수료 매출 | 18,232,800원 | 17,202,798원 | −1,030,002원 |
| 현금 운영 손익 | −2,034,040원 | −5,094,242원 | −3,060,202원 |

이 결과는 **합성 월별 거래를 통한 관리 절차 시연**이며 유료 서비스의 실제 성과가 아니다. 미관측 7~12월을 실제 발생 매출처럼 보고하지 않는다.

## CAPEX·OPEX·Headcount 경계

| 예산 구분 | 계획값·산식 | 보고·승인 원칙 |
| --- | --- | --- |
| OPEX · 현금 고정비 | 600,000원/월, 7,200,000원/년 | 인프라 15만 + 운영 도구 10만 + 모니터링 15만 + 예비비 20만. 예상 초과 전에 원인·승인 기록 |
| 초기 구축비 · 투자 후보 | 3,000,000원 계획 | 현금 투자 계획이며 회계적 CAPEX 자산 인식·감가상각은 별도 회계 판단. 기존 8주 투자 한도에 포함되므로 중복 집계 금지 |
| 인력 기회비용 · 인건비 대체 지표 | 2,000,000원/월 ÷ 25,000원/시간 = 80시간/월 | 비용 민감도 분석에 사용. 현금 급여 지급 실적과 분리 |
| Headcount 환산(계획) | 표준 160시간/월 가정 시 80/160 = **0.5 FTE** | 실제 고용 인원이나 승인 정원과 다름. 추가 인력의 투입 시간·지원 단가 확보 후 수정 |
| 추가 공급처 관리비 | 기존 5곳 초과 공급처 × 월 30,000원 | 제휴 계약·운영 기록이 아니라 공급 확대 민감도 가정. 건당 고객 지원비와 중복 배부하지 않음 |

## 수치·근거 경계

- 월 계획과 합성 거래는 `src/case-study/forecast.html`의 기존 `DATA.monthly`에서 가져온다. 투자·고정비 가정은 `docs/IT-STRATEGY-CASE-STUDY.md` 및 기존 `footmate_model.xlsx`과 구분해 대조한다.
- 수수료 매출은 거래액과 구분하고, 기대비용 모형과 거래 원장 비용을 이중 차감하지 않는다.
- 월 정상상태의 경제적 손익과 PPT 10장의 연간 투자 후 현금수지는 **기간·초기투자·인력비 포함 범위가 다르므로 직접 등치하지 않는다**.
- 보완 화면의 재예측은 새로운 분석 시나리오이며, 원본 5개년 경영계획·원본 PPT·기존 엑셀 수치를 소급 변경하지 않는다.
