# 개인 → 경기 매칭 방향 · 2026-10-23

내 수준과 포지션에 맞는 풋살 경기를 연결하고, 경기 경험을 다음 매칭에 반영한다. AI는 자연어 요구를 구조화하고, 경기 데이터와 규칙 엔진이 적합도·후보·근거를 결정한다. 사람 간 궁합·균형 팀 편성·모델 학습은 현재 범위에 포함하지 않는다.

## 1920px PC 우선 화면 기준

1920px PC를 1차 검증 대상으로 한다. 1600px 이상은 최대 1120px 앱 영역에서 두 열 경기와 근거를 비교하고 상세 정보는 나란히 확인한다. 960–1599px는 기존 560px 앱/설명 영역, 모바일은 한 열로 유지한다. Case Study 대표 캡처·와이어프레임·검증 기록도 PC를 먼저 제시한다.

## 현재 기준과 이번 변경

- 기본 프로필 추천은 선호 지역·레벨·포지션과 샘플 이동시간을 사용하며 다른 지역·실력 차이·포지션 마감은 대안의 확인 사항으로 표시한다.
- 자연어 입력에서 명시한 지역·시간·가격·거리·포지션은 후보 제한이다. 레벨은 정확히 같은 수준만 통과시키는 필터가 아니라 적합도 비교 기준이다.
- 결과가 없을 때 시간·가격·거리·포지션·지역 중 사용자가 넓혀도 되는 조건을 직접 선택한다. 선택하지 않은 조건은 유지한다. 수동 필터는 별도로 적용되므로 제한이 남을 수 있다.
- 홈은 기본 조건의 매칭 결과를 먼저, AI는 추가 요청으로 배치한다. 경기 카드에는 실제 카탈로그 기반의 맞는 점·확인할 점을 표시한다.
- 연결된 AI와 기본 검색으로 해석한 결과를 구분한다. 기본 검색을 AI 해석 성공으로 표시하지 않는다.
- 경기 후 체감 난이도·반복 의사를 기존 규칙으로 보정하며, 기본 추천과 보정 후 후보 및 근거를 비교한다. 순위 변화가 없을 수도 있다. 브라우저에만 저장하며 AI 학습으로 표현하지 않는다.

## 검증 기준

1. 서로 다른 지역·레벨·포지션에서 적합 후보와 부적합 이유를 일관되게 표시한다.
2. AI 요청 실패·0개 결과에서도 조건 출처와 유지 중인 조건을 확인할 수 있다. 완화 시 선택한 조건 하나만 제거한다.
3. 피드백 보정 후에도 큰 실력 차이·포지션 마감에 대한 우선순위 보호를 유지한다.
4. 기존 참가·취소·복구와 사용자 직접 확정은 유지한다.

## 사용자 가치 검증 · 아직 미실시

- 사용자별 조건과 두 경기 후보를 제시하고 선택·거절 이유, 맞는 점·확인할 점 이해 여부를 기록한다.
- 반드시 지킬 조건을 정한 후 결과 없음 상황에서 조건 완화를 요청한다. 유지 조건 보존과 복구 성공을 관찰한다.
- 경기 후 체감 적합도와 다음 추천 수용 여부를 기록한다. 추천 수용률은 노출·선택의 분모와 중복 제거 기준을 정의한 뒤 측정한다.
- 기존 교육생 6명 탐색·가입 과업, 규칙 기반 대체 검색 28문장 조건 일치 개선과 구분한다. QA 성공을 매칭 만족도·전환 개선으로 해석하지 않는다.
