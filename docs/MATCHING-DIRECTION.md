# 풋살 개인 → 경기 매칭 · 2026-10-27

첫 방문 활동 지역 선택 → 실력·포지션·시간 선택 → 추천 미리보기 → 기존 로그인 → /beta 홈 → 직접 참가·내 경기. WIPPY에서 참고한 것은 로그인 후 추천을 중심으로 활동·프로필로 이어지는 앱 구조이며 축구나 사람 간 궁합 매칭으로 범위를 넓히지 않는다.

## 첫 설정과 추천

- 풋살 전용이다. 축구 선택·종목 전환·11인제 경기 카드는 제공하지 않는다.
- 1단계는 활동 지역, 2단계는 실력·포지션·선호 시간이다. 문장 입력을 요구하지 않는다.
- AI는 조건에 맞는 후보 최대 12개 안에서 순서를 정한다. 없는 ID·중복 ID를 제거하고 조건을 임의 완화하지 않는다.
- 추천 화면의 빠른 필터는 기존 조건을 유지하면서 선택한 항목만 즉시 반영한다. 결과 없음의 시간·전체 조건 해제는 사용자의 명시적 선택으로만 실행한다.
- AI 추천 준비 중에는 임시 순서의 카드를 노출하지 않는다. 동일 조건의 순서 갱신은 사용자가 보고 있던 경기를 유지한다.
- `다른 경기 추천`은 AI 순서에 가중치를 두고 아직 보지 않은 후보를 무작위로 선택한다. 전부 본 뒤에는 명시적으로 다시 둘러보기를 시작하며 직전 카드는 즉시 반복하지 않는다. 방문 중 조건이 바뀌면 본 경기 기록을 초기화한다. 재추천 자체로 AI를 다시 호출하지 않는다.
- 추천 후보는 미래의 모집 중 경기와 남은 자리, 선택 포지션의 잔여 자리를 모두 확인한다. 마감·포지션 마감은 추천에서 제외하고 기존 대기 메뉴로 구분한다.
- 실제 경기와 예시 경기 모두 해당 카탈로그의 사실·자리로 추천 이유를 표시한다. AI 실패 시 기본 순서를 유지한다.

## 로그인 이후 Beta

- /demo는 로그인 전 미리보기다. 이메일·카카오·구글 로그인 후에는 /demo로 되돌리지 않고 /beta 추천 홈으로 진입한다.
- Beta 메뉴는 추천·내 경기·MY 세 개다. 추천에서 경기를 확인하고 직접 참가하면 내 경기로 이어진다. MY에서 프로필·계정·알림을 관리한다.
- 로그인만으로 자동 참가하지 않는다. 선택 경기·포지션과 브라우저 조건을 유지한다.
- 실제 미래 풋살 경기를 우선한다. 인증 후 공개된 실제 풋살 경기가 없을 때는 표시가 붙은 예시 경기 24개를 제공한다. 지역·실력·저녁 시간 조합을 포함하며 처음에는 8개씩 표시한다.
- 예시 참가·취소는 계정별 브라우저 기록으로 격리한다. 실제 경기·정원·참가 RPC·대기·알림·이메일을 생성하지 않는다.
- 실제 경기 참가·취소·체크인·피드백과 기존 서버 인증은 유지한다. 과거 취소된 QA 경기를 되살리거나 실모집으로 위장하지 않는다.
- 이전 /prototype은 과거 구현·검증 기록으로 보존한다.

## 화면·검증 기준

앱은 최대 560px 한 열, Case Study는 1920px PC를 우선한다. 텍스트·버튼·입력은 Pretendard, 의미 아이콘은 Tossface를 사용한다.

조건 유지·풋살 후보 제한·인증 후 Beta 진입·세 메뉴 전환·예시 참가/취소의 서버 쓰기 방지·실제 Beta 참가/체크인·반응형·접근성을 검증한다. 구현 QA를 매칭 만족도·전환 성과나 모델 학습으로 표현하지 않는다.


## 날짜·추천 갱신 보완
시간 필터에서 서울 날짜 기준 오늘·내일·다가오는 주말을 선택합니다. 시작 시간 상한은 해당 시각 미만이며 경기 종료 시간을 뜻하지 않습니다. 추천 캐시는 5분이며 서울 날짜·조건·후보 데이터 지문을 함께 확인합니다. AI 후보 최대 12개는 구장별 순환 선택으로 구성합니다.
