# 개인 → 경기 매칭 방향 · 2026-10-23

내 수준과 포지션에 맞는 풋살 경기를 연결하고, 경기 경험을 다음 매칭에 반영한다. AI는 자연어 요구를 구조화하고, 경기 데이터와 규칙 엔진이 적합도·후보·근거를 결정한다. 사람 간 궁합·균형 팀 편성·모델 학습은 현재 범위에 포함하지 않는다.

## 현재 출시 앱 기준

공개 /demo와 /beta는 기존 서버 연결 Beta를 연다. AI가 자연어 조건을 해석하면 공개 경기 데이터와 포지션 자리를 기준으로 후보를 정한다. 실제 Google/Kakao·이메일 로그인, 서버 프로필·참가·취소·체크인·피드백을 유지한다. 거리 데이터가 없으면 미적용을 안내하며 해석 실패 시 기존 경기 목록을 유지한다.

이전 로컬 프로토타입은 /prototype에 보존한다. 프로토타입의 레벨 정정·선택적 조건 완화·피드백 보정 UI를 현재 Beta 기능으로 표현하지 않는다. PC 우선은 Case Study의 읽기 환경에 적용하고 앱은 최대 560px·한 열로 유지한다. 앱에서는 검색·경기·로그인에 필요한 짧은 문구만 표시한다.

## 검증 기준

1. 서로 다른 지역·레벨·포지션에서 적합 후보와 부적합 이유를 일관되게 표시한다.
2. AI 요청 실패·0개 결과에서도 조건 출처와 유지 중인 조건을 확인할 수 있다. 완화 시 선택한 조건 하나만 제거한다.
3. 피드백 보정 후에도 큰 실력 차이·포지션 마감에 대한 우선순위 보호를 유지한다.
4. 기존 참가·취소·복구와 사용자 직접 확정은 유지한다.

## 사용자 가치 검증 · 아직 미실시

- 사용자별 조건과 두 경기 후보를 제시하고 선택·거절 이유, 맞는 점·확인할 점 이해 여부를 기록한다.
- 반드시 지킬 조건을 정한 후 결과 없음 상황에서 조건 완화를 요청한다. 유지 조건 보존과 복구 성공을 관찰한다.
- 경기 후 체감 적합도와 다음 추천 수용 여부를 기록한다. 추천 수용률은 노출·선택의 분모와 중복 제거 기준을 정의한 뒤 측정한다.
- 기존 교육생 6명 탐색·가입 과업, 규칙 기반 대체 검색 28문장 조건 일치 개선과 구분한다. QA 성공을 매칭 만족도·전환 개선으로 해석하지 않는다.

## 반영 상태

PR #655로 공개 진입과 UI를 실제 출시 Beta 기준으로 정정하고 운영에 반영했다. runtime 9d97cb5의 PR QA 40085073184와 main QA 40085778279는 모두 통과했다. 실제 사용자 효과 검증은 별도이며 운영 근거는 Release History를 따른다.
