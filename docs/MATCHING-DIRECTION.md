# 축구·풋살 개인 → 경기 매칭 방향 · 2026-10-24

종목·지역·실력·포지션·시간을 선택하면 나에게 맞는 실제 경기를 추천한다. 추천을 먼저 확인하고 참가할 때 로그인한다. WIPPY의 선호 기반 추천 방식을 축구·풋살 참가 맥락에 맞게 참고한다.

## 현재 출시 앱 기준

공개 /demo와 /beta는 같은 서버 연결 Beta를 연다. 첫 방문에는 조건을 선택하고, 재방문에는 저장한 조건과 추천 순서로 홈을 연다. 조건을 바꾸는 버튼은 한 곳에 둔다. 긴 소개·문장 입력·체험 선택·중복 시작 메뉴는 두지 않는다.

기본 후보는 실제 공개 경기에서 선택한 종목·지역·실력·포지션·시간과 미래 일정으로 제한한다. 종목은 기존 경기 형식 표기를 사용하며 알 수 없는 형식은 특정 종목으로 단정하지 않는다. AI에는 최대 12개의 후보를 보내 추천 순서를 받는다. 응답의 알 수 없거나 중복된 ID는 제거하고, 화면은 실제 적격 경기만 표시한다. 선택 조건을 임의로 추가하거나 완화하지 않는다. 추천 이유·잔여 자리는 경기 데이터로 표시한다.

모델 대체·시간 제한을 유지하며 AI 실패 시 선택 조건에 맞는 기본 결과를 사용할 수 있다. 후보가 없으면 없는 상태를 보여주며 예시 경기를 실제 데이터로 대신하지 않는다. 사람 간 궁합·균형 팀 편성·가짜 적합도 점수·모델 학습은 이번 범위가 아니다.

참가하기를 누르면 기존 카카오·구글·이메일 인증을 연다. 선택한 경기와 포지션은 로그인·OAuth 복귀·새로고침 뒤에도 이어서 확인한다. 로그인만으로 자동 참가하지 않는다. 참가·취소·체크인·피드백은 기존 서버 기능을 사용하며 알림·사진·계정 설정은 내 정보에서 연다.

조건·추천 순서는 현재 브라우저에 저장하고 계정·참가·피드백은 서버에 기록한다. 기기 간 선호 동기화나 피드백 학습으로 표현하지 않는다. 대기·참석 이력이 없을 때는 빈 보조 패널을 표시하지 않는다.

이전 프로토타입은 /prototype에 보존한다. 프로토타입의 자연어 해석·레벨 정정·선택적 조건 완화·피드백 보정은 해당 시점의 구현 기록으로 구분한다. PC 우선은 Case Study에 적용하고 앱은 최대 560px·한 열로 유지한다.

## 검증 기준

1. 선택한 조건이 실제 후보와 추천 근거에 일관되게 반영된다.
2. AI는 적격 후보 안에서만 순서를 바꾸며, 응답 오류·없는 경기 ID·0개 결과를 안전하게 처리한다.
3. 로그인 전 탐색이 가능하고, 참가 의도·포지션을 로그인 후에도 유지하며 자동 참가하지 않는다.
4. 재방문 복원·조건 변경·취소·체크인·피드백·내 정보 설정과 320–1920px 표시를 확인한다.

## 사용자 가치 검증 · 아직 미실시

- 서로 다른 조건의 사용자에게 후보를 제시하고 선택·거절 이유와 추천 근거 이해 여부를 관찰한다.
- 결과가 없을 때 사용자가 직접 조건을 바꿀 수 있는지 확인한다.
- 경기 후 체감 적합도와 재참가 의향, 향후 추천 개선을 별도로 검증한다.
- 기존 교육생 6명 과업·28문장 조건 해석 수치와 이번 구현 QA를 실제 매칭 효과로 해석하지 않는다.
