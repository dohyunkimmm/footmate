# Demo 화면과 사용자 흐름 개선 — 2026-11-05

대상은 현재 `/demo`와 `/beta`에서 사용하는 `src/beta` 화면이다. 보관된 `/prototype`과 Case Study의 디자인은 변경하지 않는다.

## 반영 사항

- 추천 카드 본문만 스크롤하던 구조를 제거하고 결과 화면을 하나의 스크롤 영역으로 구성한다. 날짜·실력·장소는 접지 않고, 포지션별 전체 정원은 펼쳐서 확인한다. 구장 도식과 지도 링크는 상세에서 제공한다.
- 진녹색은 참가 행동에 집중하고, 다른 추천·페이지 이동·비교는 보조 행동으로 구분한다. 비교 선택에는 라임 강조를 사용한다.
- 두 경기의 일시·장소·실력·방식·정원·선택 포지션·참가비를 표로 비교한다. 비교에서 연 상세는 비교 화면으로 돌아간다.
- 기존 날짜·시간 범위 필터를 유지한다. 시작 상한이 하한보다 빠르거나 같은 경우 저장하지 않고 안내한다.
- 결과 없음에서는 조건 하나를 해제했을 때 실제 결과가 생기는 대안과 경기 수를 제시한다. 버튼을 누르기 전에는 조건을 바꾸지 않는다.
- AI 응답 중에도 적격 후보를 먼저 표시한다. 사용자가 이미 탐색한 경기는 응답 도착 시 바꾸지 않는다. AI 실패 시 조건 기반 결과와 재시도 버튼을 제공한다.
- 로그인 입력 이름을 항상 표시하고, 선택 경기·포지션과 로그인 후 별도 참가 확정 안내를 유지한다. 포지션 설정 후에는 선택 경기로 복귀한다.
- 기존 계정/브라우저별 추천 반응에 실력 관련 반응을 추가한다. 샘플과 실제 경기 반응은 분리하고, 선택 조건을 임의로 완화하지 않는다.

## 흐름 검증

| 흐름 | 확인 기준 |
| --- | --- |
| 조건 → 추천 | 조건과 정원에 맞는 후보, 지연 중에도 정보 확인 가능 |
| 추천 → 비교 → 상세 → 뒤로 | 두 경기 유지, 비교 복귀, 제목으로 키보드 초점 이동 |
| 상세 → 로그인 → 뒤로 | 선택 경기와 상세 유지 |
| 로그인 → 참가 | 로그인만으로 참가하지 않고 사용자가 별도로 확정 |
| 참가 → 재방문 → 취소 | 기록 복원, 취소 후 빈 상태와 다음 추천 진입 유지 |
| 결과 없음 → 조건 조정 | 표시한 조건만 변경, 나머지 조건 보존 |
| 시간 범위 오류 | 오류 안내와 기존 저장 조건 유지 |

자동화는 [사용자 흐름 E2E](../tests/e2e/demo-workflow.spec.cjs), [기존 Beta 회귀](../tests/e2e/beta-core.spec.cjs), [조건 복구 계약 검사](../tests/contracts/discovery-recovery.contract.mjs)에 포함한다. 320×568·390×844·1280×720·768×375·640×720에서 핵심 정보의 내부 가림과 가로 넘침을 검사한다. 640×720은 좁은 화면 검증이며 실제 브라우저 200% 확대나 실물 기기 검증을 대체하지 않는다.

## 검증 범위

로컬 계약·경계·문서·릴리스 검사는 실행했다. Windows의 symlink 생성 권한과 브라우저 프로세스 실행 제한으로 전체 브라우저 검증은 GitHub CI에서 수행한다. 통과 여부는 이 문서 작성 시점의 추정 대신 해당 PR의 최신 필수 검사와 화면 증빙을 기준으로 판단한다.

계정 인증·참가·취소 E2E는 격리된 모의 서버를 사용한다. 실제 계정, 실물 모바일 기기, 실제 브라우저 확대 및 사용자 전환율은 별도 검증 범위다. 결제, 서버 스키마, 신규 통계 수집, 측정 동의 정책은 변경하지 않는다.
