# FootMate 포트폴리오 P0·P1·P2 반영 및 QA 기록

- 대상: `/`, `/src/case-study/materials.html`, `/src/case-study/forecast.html`, `footmate_model.xlsx`, `footmate_report.pptx`
- 기준: 실제 구현·기본 흐름 확인·합성 데이터·사업 가정을 일관되게 구분
- 원칙: 기존 9개 섹션, PPT 10장, 시뮬레이션 수치, 제품 기능을 유지하며 채용 전달력만 높임

## P0 · 주요 계산과 근거

1. `검증!B6:B9`는 예약별 원장 입력 전 `원장 입력 후 확인`으로 표시. 월간 합성집계만으로 예약별 중복·환불 검증을 완료했다고 표현하지 않음.
2. `원장입력` 시트에 예약 ID·거래월·결제·환불·수수료·결제비·CS·IT·유입비·상태 컬럼을 마련. 자료 입력 전에는 비워 둠.
3. 월별 계획과 가상 실적을 분리하고 실제 거래 원장과 구분.
4. PPT 4장: 관리비 제외 약 23곳 / 추가 관리비 포함 약 28곳을 함께 명시.
5. 웹: 12개월 고정 시나리오와 월별 성장 가정이 별개임을 안내.
6. ROI 표기를 비용 대비 예상 손익률로 명확하게 표기. 연간 수치의 원래 계산식과 단위 유지.
7. 가정 기반 수치, 실제 구현과 검증된 범위, 후속 확인 범위를 구분.

## P1 · 채용 전달력과 사업 해석

8. 첫 화면에서 검토 배경·수행 범위·핵심 판단을 우선 제시.
9. 기존 상세 분석표는 보존하면서 핵심 내용을 먼저 읽도록 편집.
10. 발표자료의 결론·전달력 향상: 설명 문구를 긍정적이고 조건 중심으로 정리.
11. PPT 5장: 손익 차이를 물량·단가·비용으로 분해.
12. PPT 7장: 기존 구현과 거래 원장·동시 요청 후속 검증을 구분.
13. PPT 8장: 36개월 기본 고정현금비이며 변동비·세금·추가 투자는 별도임을 명시.
14. 운영자 수수료 12%+결제비 부담 협상을 확정 조건이 아닌 목표안으로 표시.
15. 공급처 28곳·유지율·실제 제휴 가능성을 확장 검증 기준에 포함.
16. 주요 단위·지표 설명을 통일하고 CAC는 신규 고객 1인당 금액임을 유지.

## P2 · 구성과 사용성

17. 원본 시각 아이덴티티 유지. 발표자료 하단에 간결한 보충 문구만 추가.
18. PPT 원본 차트와 10장 미리보기 이미지를 동일 원본에서 다시 생성.
19. 웹 첫 섹션에 핵심 요약·손익·IT·첨부자료 이동 링크를 추가.
20. 모바일 폭, 키보드 탐색, 발표자료 이동·전체 화면·자료 링크는 PR의 Case Study 브라우저 QA를 활용.

## 독립 QA

- **엑셀 구조:** 6개 시트, 기존 계획·실적 원천 수치 보존, 예약 원장 입력 전 검증 표현 확인.
- **금액 정합:** 상반기 합성+하반기 계획 연간 현금 운영손익 약 −303.3만 원, 12개월 합성 비용 추세 가정 약 −484.1만 원.
- **PPTX:** 10장 유지, 기존 편집 가능 차트 유지, 4·5·7·8·9장 문구 반영.
- **미리보기:** PPTX 재렌더링 PNG 10개를 웹 페이지에 반영.
- **웹 동작:** 기본 스크립트 문법·자산 버전 검증 후 기존 PR 모바일/접근성/브라우저 QA 수행.

이 문서는 수정의 근거와 재현 기준을 기록합니다. 브라우저 QA 및 배포 상태는 각 GitHub Actions 실행 결과와 배포 이후 확인으로 최종 판단합니다.
