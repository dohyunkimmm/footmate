# FootMate v4.8 Platform Architecture

v4.8은 v4.7의 사용자 경험을 유지하면서 실제 provider 연동을 받을 수 있도록 cross-cutting runtime 경계를 분리한다.

## Layer ownership

- `src/v4/platform/domain/` — session/event schema와 migration 규칙. DOM·localStorage를 모른다.
- `src/v4/platform/application/` — session lifecycle, event log ordering·dedupe. provider 구현을 직접 모른다.
- `src/v4/platform/infrastructure/` — browser/memory storage provider와 JSON repository.
- `src/v4/platform/presentation/` — 기존 v4 UI와 platform application 사이의 compatibility bridge.
- 기존 `src/v4/*.js` feature module은 v4.8에서 동작 보존을 우선하는 compatibility runtime이다. v4.9 이전에 임의로 전면 재작성하지 않는다.

## Session contract

- Storage: `footmate:v4:session`
- Current schema: `2`
- legacy/unversioned session은 bootstrap 시 schema v2로 migration한다.
- 기존 extension field는 compatibility를 위해 보존한다.
- invalid known field만 안전한 기본값으로 정규화한다.

## Repository / provider

현재 Production provider는 browser `localStorage`다. `createBrowserStorageProvider`, `createMemoryStorageProvider`, `createJsonRepository`, `createRepositories`를 통해 저장소 접근을 교체 가능하게 만든다.

회원 DB나 서버 persistence가 연결된 것은 아니다. memory provider는 deterministic contract test fixture 전용이다.

## Event contract

현재 event schema는 `1`이며 local event log `footmate:v4:events`에 최대 100개를 보관한다.

- `recommendation.selected`
- `join.started`
- `join.completed`
- `checkin.completed`
- `postgame.submitted`

`join.completed`, `checkin.completed`, `postgame.submitted`는 동일 domain action의 reload/retry 중복을 막을 수 있도록 dedupe key를 지원한다.

이 event log는 외부 analytics 전송이 아니다. v4.8은 naming·payload·ordering contract만 검증한다.

## Validation

- `tests/contracts/v4.8-platform.contract.mjs` — memory provider 기반 deterministic contract
- `tests/e2e/v4-platform.spec.cjs` — browser session migration + event bridge
- 기존 v4 discovery/decision/participation/matchday/return/personalization 회귀 유지
- exact Production HTTP + Chromium smoke
