# FootMate 코드 검토 · 2026-09-10

기준: GitHub `main`. 승인된 프로토타입 원본 `demo.html` / `demo-source.html`은 유지하고, `/demo` 런타임 레이어에서 상태·추천·검증 로직을 보완했습니다.

## 이번 완료 범위

- 39개 화면 Deep Link·브라우저 이력, 퀴즈 중복 진행, 화면 이탈 타이머, 수동 지역, 결제수단·영수증, IME·키보드 등 기존 회귀 수정은 유지했습니다.
- 날짜·지역·시간대·거리·경기 방식·모집 포지션을 실제 후보 eligibility와 추천 정렬·빈 결과 상태에 연결했습니다.
- 홈의 `어제 / 오늘 / 내일`과 `모집 중 / 내 ELO ±50 / 5km 이내`를 실제 홈 경기 카드의 노출·건수·빈 상태에 연결했습니다.
- 선택 경기 → 상세 → 결제 → 참가 상태의 경기 식별자를 유지하고, 대체 참가 제안은 화면의 경기 정보에서 대상 경기 키를 파생하도록 일반화했습니다.
- 경기 결과로 갱신된 ELO를 다음 추천과 프로필에 반영하고 핵심 진행 상태를 새로고침 후 복원합니다.
- 크레딧을 단일 잔액 상태로 통합하고 충전·참가 결제·프로필 잔액을 동기화했습니다. 같은 경기의 중복 차감을 방지합니다.
- 상태 복원을 홈 필터, 크레딧, 평가 별점, 즐겨찾기, 친구 추가, 사용자 채팅까지 확장했습니다.
- Data Quality의 Consistency는 참가 경기·결제 이벤트·선택 경기 연결 키를 검사하고, Traceability는 핵심 퍼널 이벤트 5개의 존재와 순서를 검사합니다. Freshness는 실제 서버 데이터가 없는 샘플이므로 `SAMPLE`을 유지합니다.
- 데모의 `AI 로직` 버튼은 실제 구현 경계를 더 정확히 설명하도록 `매칭 로직`으로 변경합니다.
- `/demo` 셸은 원본 HTML을 같은 문서에 로드하고 런타임 자산을 주입하도록 변경해, 데모 내부의 추가 iframe 중첩을 제거했습니다. 케이스 스터디의 데모 iframe 한 단계만 유지됩니다.
- 케이스 스터디 IA 설명은 실제 하단 내비게이션인 `홈 · 탐색 · 일정 · 프로필` 4개 탭과 맞추도록 런타임에서 동기화합니다.

## 자동 검증

Node.js 20 이상에서 별도 패키지 설치 없이 실행합니다.

```sh
node --test tests/*.test.cjs
```

- `tests/regression.test.cjs` — 기존 프로토타입 회귀 20개: Deep Link, 화면 이력, 퀴즈·타이머, 지역·결제·참가 상태, ELO, 한글 IME·키보드 등.
- `tests/runtime-patch.test.cjs` — 런타임 일관성 9개: 실력 단계, 현재 ELO carry-forward, 하드 필터, 추천 정렬, Data Quality, 퍼널 이벤트 순서, 상태 연결 키, 홈 필터, 크레딧 증감.

신규 런타임 테스트 9개는 로컬 Node.js 실행에서 모두 통과했습니다. 승인 원본 `demo.html`은 기존 20개 회귀 테스트를 통과한 버전과 동일하게 유지합니다.
