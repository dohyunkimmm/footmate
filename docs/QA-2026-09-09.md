배포 상태와 실제 화면 검증도 구분해야 합니다. 이 기록 자체는 Production의 브라우저 검증 증거가 아닙니다.

## 남은 개선 사항

- 홈 날짜·필터 탭은 선택 스타일 위주로 동작하며, 실제 후보 목록을 필터링하지 않습니다. 날짜 탭의 헤더 갱신 선택자도 수정이 필요합니다. 날짜별 샘플 경기 데이터와 필터 기준을 정의한 뒤 목록·건수·빈 결과 상태를 함께 연결해야 합니다.
- 매칭 조건의 날짜·최대 이동 거리는 화면 입력 상태이며 실제 추천 점수·후보 제외까지 연결되어 있지 않습니다. 현재 추천은 기존의 다섯 입력을 기준으로 계산합니다.
- 데이터 품질 화면의 Consistency·Traceability는 정적인 PASS 표기를 사용합니다. 실제 이벤트 순서와 연결 키를 검증하는 판정으로 확장할 필요가 있습니다.
- 실제 결제·로그인·위치·외부 AI·DB·알림은 기존과 같이 미연동입니다. 이 항목들은 이번 버그 수정의 완료 범위에 포함하지 않습니다.
