# FootMate IT기획·전략기획 Case Study

기준일: 2026-10-30

기존 서비스기획 공개 구성은 아래 9개 섹션으로 교체한다. 페르소나·여정·IA·와이어프레임·화면별 UX 소개는 공개 케이스 스터디에서 제거한다. 제품 데모와 서버 기능은 변경하지 않는다.

1. 추진 배경·검토 결론
2. 시장·경쟁 분석
3. 사업모델·역할
4. 수요·공급 시나리오
5. 수익성·손익분기점
6. IT 투자·시스템 구조
7. 운영 위험·통제
8. 실행계획·성과관리
9. 종합 판단·근거

시장·사업성 분석은 이번 재구성에서 신규 작성한 검토이며 과거 수행 실적으로 소급하지 않는다. 출처·가정·수식과 현재 구축 근거는 [IT-STRATEGY-CASE-STUDY.md](IT-STRATEGY-CASE-STUDY.md)를 따른다.
