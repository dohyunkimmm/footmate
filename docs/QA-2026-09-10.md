- **P1**: `.github/workflows/qa.yml`을 추가해 `main` 대상 Pull Request와 `main` push에서 Node.js 20 회귀 테스트를 자동 실행하도록 구성했습니다.
- **P2**: 즐겨찾기는 경기 key(`favoriteMatchKeys`), 친구 추가는 멤버 ID(`friendIds`) 단위로 저장·복원하도록 변경했습니다. 이전 boolean 저장값은 ID 기반 상태로 1회 마이그레이션합니다.

## 자동 검증

Node.js 20 이상에서 별도 패키지 설치 없이 실행합니다.

```sh
node --test tests/*.test.cjs
```

테스트는 세 그룹으로 구성합니다.

- `tests/regression.test.cjs` — 기존 프로토타입 회귀 20개: Deep Link, 화면 이력, 퀴즈·타이머, 지역·결제·참가 상태, ELO, 한글 IME·키보드 등.
- `tests/runtime-patch.test.cjs` — 런타임 일관성 9개: 실력 단계, 현재 ELO carry-forward, 하드 필터, 추천 정렬, Data Quality, 퍼널 이벤트 순서, 상태 연결 키, 홈 필터, 크레딧 증감.
- `tests/quality-hardening.test.cjs` — 품질 보강 회귀 7개: Case Study shell 동기화, 승인 Demo 원본 동기화, Production 메타데이터, 런타임 스크립트 문법, 저잔액 화면 이동 무부작용, ID 기반 persistence, 이전 저장값 migration.

GitHub Actions는 Pull Request와 `main` 반영 시 위 전체 테스트를 동일한 명령으로 실행합니다.
